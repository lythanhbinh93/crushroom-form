### Security & Anti-Enumeration Analysis

#### Anti-Enumeration Logic: `addMember()`

**Finding:** SECURE — No enumeration leak detected.

**Reasoning:**
1. **Silent success behavior:** The RPC `add_workspace_member_by_email` is a void function that returns without error in all three paths:
   - Email exists, not yet a member → inserts membership
   - Email doesn't exist → no-op (silent)
   - Already a member → no-op via ON CONFLICT (silent)

2. **Response shape identical:** The action always returns the same generic message:
   ```typescript
   "If ${email} is registered, they now have access — they'll see the brand on next login."
   ```
   This message is returned regardless of which code path executes within the RPC.

3. **Error handling:** Only surfaces non-sensitive errors:
   - `forbidden` → ownership check (not enumeration-sensitive)
   - All other errors → generic "failed to process invite" (swallows technical details)

4. **Test coverage:** Test "returns identical generic message regardless of RPC outcome (anti-enumeration)" explicitly validates that success response is generic. ✓

**Threat model:** An attacker cannot differentiate between "user@example.com is registered but not yet invited" and "user@example.com doesn't exist" by observing the response.

#### Last-Owner Protection: Trigger + Tests

**Finding:** SECURE — Comprehensive test coverage for last-owner constraint.

**Trigger Implementation (migration 0011):**
```sql
create trigger prevent_last_owner_removal
  before delete or update on public.workspace_members
  for each row execute function public.check_last_owner();
```

**Function logic:**
- Counts remaining owners excluding the row being modified
- If count = 0, raises: `'cannot remove or demote the last owner'`
- Covers both DELETE (removal) and UPDATE (demotion) operations

**Test Coverage:**

| Test Case | Location | Status |
|-----------|----------|--------|
| Remove last owner (DELETE) | `removeMember > surfaces last-owner trigger error message` | **PASS** ✓ |
| Demote last owner (UPDATE) | `setMemberRole > surfaces last-owner trigger error on demotion attempt` | **PASS** ✓ |
| Error message surface | Both tests assert `error.message.includes("last owner")` | **PASS** ✓ |

Both tests mock the DB error response and verify the action correctly surfaces the trigger exception with the exact message string.
