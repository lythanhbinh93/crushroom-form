# Route Patches — Manual Changes Required After File Copy

These changes must be made manually in the target app
(`D:\github local\dopamiles-bundle-app\`) because they touch files
auto-generated by `shopify app init` that this scaffold does not own.

---

## 1. Add nav link to Bundle Config page

**File to edit:** `app/routes/app.tsx`  
(Auto-generated by Remix template; contains the `<NavMenu>` component.)

Locate the `<NavMenu>` block — it looks roughly like:

```tsx
<NavMenu>
  <Link to="/app" rel="home">Home</Link>
  {/* other links */}
</NavMenu>
```

Add one `<Link>` entry:

```tsx
<Link to="/app/bundle-config">Bundle Config</Link>
```

**Result:** Shopify admin sidebar will show "Bundle Config" under your app's
navigation section.

---

## 2. Confirm `shopify.server.ts` export

**File to check:** `app/shopify.server.ts`  
(Auto-generated; exports `authenticate` used by the bundle-config route.)

Verify the file exports `authenticate`:

```ts
export const { authenticate, ... } = shopifyApp({ ... });
```

If the export name differs, update the import in
`app/routes/app.bundle-config.tsx`:

```ts
// Change this line:
import { authenticate } from "../shopify.server";
// To whatever your file exports, e.g.:
import { authenticate } from "../shopify.server.js";
```

---

## 3. Update `shopify.app.toml` scopes

**File to edit:** `shopify.app.toml`

Ensure `scopes` includes all of:

```toml
scopes = "read_products,write_discounts,read_discounts,write_metafields"
```

`write_metafields` is required for `metafieldsSet` on the shop owner.
Without it, the Save action returns a 403 user error.

After updating scopes, run:

```powershell
shopify app deploy
```

And re-install the app on the dev store to accept the new scope permissions.

---

## 4. (Optional) Add `monospaced` prop polyfill check

Polaris `TextField` `monospaced` prop was added in v12. If your project
uses an older Polaris version, replace it with a CSS workaround:

```tsx
// Instead of monospaced prop:
<TextField
  label="Tiers (JSON)"
  style={{ fontFamily: "monospace" }}   // not standard Polaris API
  ...
/>
```

Preferred: upgrade to `@shopify/polaris@^12.0.0`.
